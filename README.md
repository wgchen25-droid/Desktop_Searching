# Desktop Searching

德国 / 欧洲市场高性价比桌面工作站与工程电脑的长期价格追踪项目。

## 目标

寻找适合长期远程使用、运行工程软件、具备一定五年升级空间的 Desktop / Workstation，重点捕捉短期异常折扣和“错过后很难再遇到”的 Angebot，而不是每天强行推荐一台普通机器。

## 当前搜索原则

- **主要预算区间：€900–€1,300**
- **扩展观察区间：€1,300–€1,600**，仅当性价比显著异常时重点推荐
- 用途：均衡型工程软件、远程多屏使用、长期放置于角落/地下室作为主机
- 重点考虑：CPU、GPU、RAM、SSD、网络、稳定性、远程使用体验、功耗与散热
- 优先标准化、可升级平台：RAM 插槽、M.2、PCIe、标准 ATX/mATX、电源与机箱空间
- 全新优先；可接受官方 Outlet / Refurbished / Warehouse 等，但必须有可靠商家、清晰保修和售后
- 德国市场优先；可纳入能可靠配送德国且售后可接受的欧洲卖家
- 不以商家标称 UVP 折扣作为主要判断依据，而以真实市场成交价、同级配置和历史价格比较

## 固定硬件 Reference

除了市场历史价格，还维护独立的固定硬件基准，用来回答“新 Angebot 相比已知机器到底提升了什么”。固定基准与市场报价历史分开保存，避免未知价格污染 7 天 / 30 天价格趋势。

当前 Reference：

- **HP Z2 Tower G9 Workstation**
  - CPU：Intel Core i7-12700K
  - RAM：32 GB
  - Graphics：Intel UHD Graphics 770
  - 角色：固定硬件 / 配置对比基准
  - 价格：未提供，因此不得把它当作历史成交价或市场价样本

每日搜索除了比较当前市场与历史价格，也应比较候选机相对 Reference 的 CPU、GPU、RAM、工程软件适配、远程主机能力和升级空间；涉及具体性能差距时优先使用可核验 benchmark，而不是凭型号直接估算百分比。

## 每次搜索必须回答的问题

1. 今天最值得关注的 Angebot 是什么？
2. 它相对当前同级市场价格便宜多少？
3. 它相对本项目过去搜索记录，是更便宜还是更贵？
4. 性价比趋势是在改善、持平还是恶化？
5. 价格优势来自哪里：CPU、GPU、RAM、SSD、整机清仓、Outlet，还是商家短时促销？
6. 工程软件、远程使用、长期稳定性和未来升级性是否存在明显短板？
7. 保修、退货、售后和商家可靠性是否足够？
8. 现在错过以后，类似价格是否容易再次出现？
9. 相比固定硬件 Reference，实际升级点和退步点分别是什么？

## 推荐等级

- 🔥 **错过可惜**：价格明显脱离近期正常区间，值得优先检查库存与购买条件
- ✅ **很值**：当前买入性价比优秀，长期看不容易吃亏
- 🟡 **普通好价**：可以考虑，但不值得因为促销倒计时冲动购买
- ❌ **跳过**：折扣看起来大，但真实价值不足或存在明显短板

同时记录一个 **后悔风险 / 机会稀缺度（1–10）**，用于判断“不买之后是否大概率难以再次遇到”。

## 数据结构

- `reports/YYYY-MM-DD.md`：每次搜索的完整总结与当日结论
- `data/price_history.csv`：持续累积候选机器和价格，用于跨日、跨周、跨月比较
- `data/reference_systems.csv`：固定硬件 Reference，只做配置 / 性能对比；没有明确价格时不得计入市场价格历史

如果一天内有多次搜索，可使用 `reports/YYYY-MM-DD-HHMM.md`。

## 连续比较原则

每日结论不能只依据当天价格。搜索时应读取既有历史记录和固定 Reference，并比较：

- 过去 7 天 / 30 天同档位最好价格
- 类似 CPU/GPU/RAM 配置的历史价格
- € / 性能与整机组件价值
- RAM 容量和内存市场变化对整机价值的影响
- 当前同样预算可以买到的性能是否比过去提升
- 候选机相对固定 Reference 的真实性能、功能和升级变化
- 优惠的稀缺程度和重复出现概率

没有真正值得购买的 Angebot 时，应明确记录“今日无强推荐”，而不是为了凑数推荐普通机器。
