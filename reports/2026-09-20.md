## 为什么 Acer 仍是今日总冠军

Acer 的强项是把 **RTX 5070 12GB + Windows 11 Home + 850W PSU** 压进 €1,159 的实际现金支出。精确 Acer 数据表确认 DG.E4UEG.003 使用 i5-14400F、RTX 5070 12GB、16GB DDR4 (2×8)、1TB M.2 SSD、Gigabit Ethernet、Wi-Fi 6E、1×HDMI + 3×DisplayPort，以及 850W 电源。它因此很适合当廉价 CUDA / GPU rendering / 本地 AI / NVIDIA 加速工程节点或远程 3D 主机。

但它绝不是完美五年 workstation 底座：公开精确规格只有 **2 个 DIMM，当前已占满，最大 32GB**；扩内存必须把两根 8GB 一起换掉。扩展接口也很有限：1×PCIe x16、1×PCIe x1，存储侧 1×M.2 SSD + 1×M.2 WLAN。主板属于 Acer OEM / H610 级平台，LGA1700 / DDR4 也已经没有现代 AM5 那种 CPU 路线，因此五年升级分仅 4.3/10。换句话说，这台适合“低成本买强 GPU，用四五年，中间换 RAM/SSD”，不适合“未来持续换 CPU、扩 64/128GB RAM、堆多块 PCIe 卡”。

## Acer vs CSL：多 €140 到底买到什么

**Acer €1,159 → CSL €1,299，多 €140**：GPU 从 RTX 5070 12GB 降为 RTX 5060 Ti 16GB，Windows 11 Home 也没有了，系统 RAM 仍只有 16GB，PSU 还从 Acer 850W 降到 500W；所以即时 GPU 性能 / 开箱完整度是 Acer 更划算。

但 CSL 这 €140 买的是完全不同的平台路线：全新机、AM5 / B840 / DDR5、标准 mATX、4 DIMM、3 M.2、2.5GbE、Wi-Fi 6E、标准件维护与 24 个月厂家保修。对于“地下室长期放置、几年后再换 CPU / 64GB RAM / 多 SSD”的使用方式，这些比单纯显卡快一档更有长期价值。若未来要上更高功耗 GPU，CSL 的 500W PSU 应视为第一批要换的部件；Acer 的 850W 在这点反而更宽裕。

## 相对固定 Reference：HP Z2 Tower G9 (i7-12700K / 32GB / UHD 770)

Reference 继续严格作为**固定硬件对照**，其价格为空；本日报没有把它写入 `price_history.csv`，也没有让它参与 7 日 / 30 日均价、市场折扣或历史最低价统计。

对今日 Acer 冠军，结论是非常明确的“**GPU 大升级、CPU 与 RAM 退步**”。同一 PassMark 数据口径下，i7-12700K 约 34,247 CPU Mark / 4,003 单线程，i5-14400F 约 25,439 / 3,701；也就是合成分方向上约 **-25.7% 多线程、-7.5% 单线程**。这只是合成 benchmark，不能直接等同于 ANSYS / Abaqus / MATLAB / SolidWorks 的真实差距，但足以说明 CPU-only solver、编译、CPU rendering 不应为了这台 Acer 替换 Z2。

GPU 则相反：从 UHD 770 到 RTX 5070 12GB，CUDA / OptiX、GPU rendering、NVIDIA GPU solver、本地 AI、复杂 3D 视口会获得现有 Reference 不具备的独显计算能力。没有针对具体工程软件统一可靠的公开百分比，因此这里只做定性判断，不编造“快几倍”。RAM 从 Reference 的 32GB 降到 Acer 的 16GB 是明确退步；并且 Acer 最大仅 32GB，所以即使升级也只能追平 Reference 容量，无法走向 64/128GB。

远程主机方面，Acer 的 1GbE + Wi-Fi 6E 足够稳定使用，固定放地下室仍建议主链路走有线。Windows 11 Home 如果依赖微软原生 Remote Desktop 做被控 Host，需要升级到 Pro 或改用其他远程方案。散热/功耗上，14400F 本身比 12700K 更低功耗，但加入 RTX 5070 后，GPU 高负载时整机热量会明显高于仅使用 UHD 770 的 Reference；长期角落/地下室运行应确保进排风不被堵住、减少灰尘并定期清理。

**所以：如果 Z2 真正瓶颈是 CUDA / GPU / 3D / AI，Acer €1,159 值得替换；如果主要瓶颈是 CPU-only 或需要 >32GB RAM，则今天不应该为了 RTX 5070 的低价而换。**
