## 为什么 Acer 仍然赢

Acer 的优势是把 **RTX 5070 12GB + 850W Gold + Windows 11 Home** 压到 €1,159 的实际现金支出，而且销售方、保修和退货都能明确核验。对 CUDA、OptiX、GPU rendering、NVIDIA GPU solver、本地 AI 与复杂 3D 视口，它是当前主预算内最强的可核验 GPU/欧元路线。

今天需要把“优惠幅度”与“绝对价值”分开：同 SKU 新机最低已经能到 €1,199，因此 refurb 只比最低新机便宜 €40；**它赢不是因为 refurb 折扣巨大，而是因为这台 exact SKU 本身的 RTX5070 获取成本非常低**。如果你极度在意全新状态，那么多 €40 购买最低新机 Marketplace 版本在纯价格上也很有吸引力，但因为最低新机卖家的精确保修/退货没有在本轮完成同等强度核验，所以不取代 AcerSonderposten 作为正式冠军。

Acer 的长期短板仍然很明确：OEM / H610-class、LGA1700、DDR4、只有 2 DIMM / 最大 32GB、PCIe/M.2 扩展有限以及专有零件风险。它更像“便宜买强 GPU 的长期远程节点”，而不是 64/128GB 大内存、不断换 CPU / PCIe 卡的通用 workstation 平台。

## Acer vs Cyberport：多 €100 买到什么

**Acer €1,159 → Cyberport Hyrican €1,259，多 €100。** Cyberport 方案把机器状态从 refurb 变成全新、销售渠道从专业 refurb 店换成德国大型零售商直售，并把 RAM 上限从 32GB 提高到 64GB；RTX 5060 Ti 的 **16GB VRAM** 在部分显存容量优先的 CUDA / AI / 大纹理场景中也可能比 12GB 更从容。

但这 €100 并没有买到更强的总体 GPU 档位：RTX5070 仍然是更高一级的 raw compute / rendering GPU。Hyrican 的 400W PSU 还是未来独显升级的明显障碍，AM4/DDR4 的 CPU 平台也接近终点；网络为 1GbE + Wi‑Fi5。Acer 则有更大的 850W 电源余量。对“现在就要 GPU 工程能力”，Acer 更值；对“全新机、德国大型零售商、可能需要 64GB RAM”，Cyberport 是今天最合理的不同商家替代。

## CSL 今天为什么降级

CSL Sprint 5753 昨天仍是 €1,299；今天官方已经到 **€1,399**，即 **+€100 / +7.7%**，同时主板从此前跟踪的 ASUS PRIME B840M-A WIFI 漂移为 **GIGABYTE B840M DS3H WIFI6**。当前板仍是标准 mATX / AM5 / DDR5 平台并具备 4 DIMM、2×M.2、2.5GbE 和 Wi‑Fi6，因此五年升级性仍优于 Acer / Hyrican；但今天相对 Acer 的差价扩大到 €240，而且 GPU 档位更低、无 OS、仅 16GB RAM、500W Bronze。现在买等于为平台未来性支付明显溢价，因此评级降为 **🟡 普通好价 / 等待回落**。

## 远程主机与长期运行

Acer 的 1GbE 建议走有线作为地下室主链路，无线只作为备用管理；RTX5070 的多显示输出对本地多屏也足够。Windows 11 Home 如果要作为微软原生 Remote Desktop 被控 Host，需要升级到 Pro，或者使用其他远程方案。长期 GPU 高负载下，整机热量会明显高于只使用核显的办公主机，因此地下室/角落部署应留足进排风空间、处理灰尘并定期清理。

Cyberport Hyrican 同样适合有线远程，但 Wi‑Fi5 比 Acer / CSL 更旧；其 400W PSU 对未来 GPU 换代不友好。CSL 的 2.5GbE / Wi‑Fi6 与标准 mATX 更适合作为长期可维护网络节点，但当前价不值得为了这些特性立即追高。

## 相对固定 Reference：HP Z2 Tower G9 / i7-12700K / 32GB / UHD 770

`data/reference_systems.csv` 中的 HP Z2 继续严格作为 **hardware_reference**：i7-12700K / 32GB / UHD 770，`price_eur` 为空。本日报没有把它写入 `price_history.csv`，也没有让它参与市场折扣、7日/30日均值或历史最好价统计。

相对 Reference，Acer 是**GPU 大升级、CPU 与 RAM 退步**。当前公开 PassMark 同一数据库口径：i7-12700K 约 **34,247 CPU Mark / 4,003 单线程**，i5-14400F 约 **25,439 / 3,701**；即 i5-14400F 在该合成口径约低 **25.7% 多线程、7.5% 单线程**。这只能说明方向，不能直接等同于 ANSYS / Abaqus / MATLAB / SolidWorks 的实际工作负载百分比。因此 CPU-only solver、CPU rendering、编译和 CPU 敏感 CAD **不是**换 Acer 的理由。

GPU 则相反：RTX5070 公开规格为 **6,144 CUDA cores、12GB GDDR7**。从 UHD 770 到 RTX5070，对 CUDA / OptiX、GPU solver、本地 AI、GPU rendering 与复杂 3D 视口属于能力层面的跃升。由于没有针对用户具体工程软件的一致公开 benchmark，这里不编造“快几倍”。RAM 从 Reference 的 32GB 降到 Acer 的 16GB，而且 Acer 最大只能到 32GB，因此大内存工程任务最多只能追平 Reference，不能扩展到 64/128GB。

功耗/散热方面，Acer 的 CPU 本身并不是换机的理由，但加入 RTX5070 后，GPU 高负载下整机热量会明显高于当前仅使用 UHD770 的 Reference；地下室长期运行需要按独显工作站布置风道和清灰。
