## Acer vs Cyberport：€100 的实际交换

Cyberport 多 €100 的主要价值是 **Refurbished → New、专业翻新店 → 大型零售商直售、公开 RAM 上限 → 64GB**，外加 RTX5060Ti 的 16GB VRAM。在显存容量先于 raw compute 的局部 CUDA / AI / 大纹理工作中，16GB 显存可能比 12GB 更从容。

但 RTX5070 的总体 GPU 档位更高，Acer 又是 850W，而 Hyrican 只有 400W。后者未来换高功耗 GPU 基本要先换电源；AM4/DDR4 CPU 路线也已接近终点。**现在就要 GPU 工程能力和价格效率：Acer；更重视全新状态、Cyberport 售后和明确64GB内存上限：Hyrican。**

## Acer RAM / 主板信息：保守估值

公开 exact-SKU 规格存在冲突：Kaufland 分销商数据把 DG.E4UEG.003 对应到 H610、2 DIMM、最大32GB；Idealo 的问答则曾给出64GB。因此不把“64GB”当成已证实事实，也不把“32GB”写成绝对硬限制。若64GB是刚需，下单前应向 Acer / GG-Net 获取 exact SKU 的官方上限与当前占槽方式。

M.2 / PCIe 同样按 OEM 紧凑平台保守估值，不把价格比较站的泛化字段当主板级保证。未来若要多块NVMe、10GbE、采集卡或其他PCIe工程卡，标准 ATX/mATX 的 AM5/B850 平台更适合。

## 远程主机与地下室长期运行

Acer 自带 Windows 11 Home；微软官方要求作为原生 Remote Desktop 被控端的PC运行 Windows Pro，因此若坚持原生RDP，要把升Pro算入成本，或使用其他远程方案。NVIDIA官方RTX5070规格为 **6144 CUDA cores、12GB GDDR7**；对 CUDA、OptiX、GPU rendering、本地AI和NVIDIA GPU加速工程任务是结构性能力提升。

地下室长期运行仍建议：有线Ethernet做主链路，无线仅作备用；保留机箱前后进排风空间；建立清灰周期。RTX5070持续高负载时整机热量会明显高于仅使用UHD770的现有Z2。
