## 今日总冠军：CSL Sprint 5753 €1,299

### CPU / GPU / RAM

Ryzen 7 8700F 是 8 核 16 线程 AM5 CPU。相对固定 HP Z2 Reference，它不是一个值得单独为 CPU 换机的升级：CPU-only solver、CPU 渲染、编译等不能期待稳定加速，部分工作负载 Reference 仍可能更快。

真正的结构性升级来自 **RTX 5060 Ti 16GB**。NVIDIA 官方规格为 4608 CUDA cores、16GB GDDR7。CUDA、OptiX、GPU 渲染、本地 AI、部分 NVIDIA GPU solver、显存敏感数据集和重 3D 视口，是它相对 UHD 770 的真正价值；普通 Office、2D CAD、纯 CPU 求解则不会因为独显自动变快。

开箱 **16GB DDR5 (2×8GB)** 相对 Reference 的 32GB 是明确退步，因此第一笔升级应当是 32GB，复杂仿真、大装配、多 VM 或多软件并行长期建议 64GB。

### 主板 / M.2 / PCIe / 网络 / 标准件风险

ASUS PRIME B840M-A WIFI 是标准 mATX / AM5，官方规格为 4 个 DDR5 DIMM、3 个 M.2、1× PCIe 4.0 x16 主显卡槽、额外 PCIe 扩展、2.5GbE、Wi‑Fi 6E。机箱、电源、主板和独显均为常规桌面形态，专有零件锁定风险比典型 OEM 低。

500W 80+ Bronze ATX2.4 是最明显的五年限制：当前配置可用，但未来换高功耗 GPU 时 PSU 应作为优先升级项。好处是它是标准 ATX 电源，不存在 OEM 专用接口锁死。

### 散热 / 稳定性 / 地下室部署

8700F 搭配 Deepcool Gammaxx C40 空冷，商品页没有长期满载温噪实测，因此不对 24/7 满载温度做无依据保证。长期放角落/地下室应保留机箱前后风道、不要贴墙，并定期清灰。CSL 提供出货前功能测试、兼容性检查、德国组装、2 年保修可扩至 3 年和终身技术支持，售后链路清楚。

### 远程主机

2.5GbE 应作为主链路，Wi‑Fi 6E 适合作为备用管理路径。RTX 5060 Ti 有 1×HDMI + 3×DisplayPort，物理多屏没有问题。缺点是 8700F 无核显：独显故障或驱动严重异常时，没有 Reference 的 UHD 770 独立后备显示路径。整机不含 OS；如果计划使用微软原生 RDP Host，建议安装 Windows 11 Pro。

## 最佳非同商家挑战者：Captiva Workstation I10-2574 €1,299

这台是今天最值得加入跟踪的新机器。NBB 与 Nullprozentshop 对同一精确型号都显示 **€1,299**，因此当前合理市场参考就是 €1,299，不拿 UVP €1,699 当“折扣”。

Captiva 官方规格：Intel Core Ultra 7 270K Plus、24 核、B860M / LGA1851、32GB DDR5-5200、1TB M.2、Intel Graphics、Windows 11 Pro、Wi‑Fi 6、1GbE、550W 电源、空气散热，最大 RAM 官方标 128GB。它开箱就比 CSL 更适合纯 CPU 工程计算、VM、多任务和原生 RDP；32GB RAM 也比 CSL 的 16GB 更合理。

但它不是 GPU workstation。集显对 CUDA/OptiX/NVIDIA GPU solver 没有替代能力，3D/GPU 渲染也远落后于 RTX 5060 Ti。550W PSU 让后续加 RTX 5070 级别显卡时最好同步换电源；如果只加较低功耗 GPU，仍需核对具体卡和电源接口/余量。

### 相对固定 Reference 的真实 CPU 升级

PassMark 2026-09-10 数据中，Core Ultra 7 270K Plus CPU Mark 约 **68,436**、Single Thread **5,071**；i7-12700K 为约 **34,251 / 4,003**。按同一数据库口径，前者 CPU Mark 约高 **99.8%**、单线程约高 **26.7%**。这只是合成 benchmark，不能直接外推成某个 ANSYS / Abaqus / SolidWorks / MATLAB workload 同样快 99.8%，但足以证明 CPU-heavy 方向是实质升级。

相对 Reference：RAM 同为 32GB，但从 DDR4/DDR5 代际取决于 Reference 实际模块配置；这里不把内存带宽提升硬写成应用百分比。GPU 仍是集显路线，因此若当前 Z2 的真正瓶颈是 UHD 770 / CUDA 缺失，这台不是完整替代。

## 固定 Reference：HP Z2 Tower G9 / i7-12700K / 32GB / UHD 770

Reference 的价格为空，继续严格留在 `data/reference_systems.csv`，不写入 `price_history.csv`，不参与 7 日/30 日均价、市场折扣或历史最低价统计。

对今日冠军 CSL 5753：

- **CPU：** 不构成明确升级，CPU-only 工作不应为了 8700F 换机。
- **GPU：** UHD 770 → RTX 5060 Ti 16GB 是结构性升级，真正受益的是 CUDA/OptiX/GPU 渲染/AI/重 3D/支持 NVIDIA 的 GPU solver。
- **RAM：** 32GB → 16GB 开箱明确退步；必须优先补到至少 32GB。
- **远程：** 2.5GbE + Wi‑Fi 6E 更现代，但无 OS；原生 RDP 需自行装 Pro；8700F 无 iGPU 故障后备。
- **功耗/散热：** 加入 RTX 5060 Ti 后 GPU 满载整机功耗肯定高于仅 UHD 770 的 Reference；地下室长时间 GPU 负载应更关注进风、灰尘和散热。
- **五年升级：** AM5/B840、4 DIMM、3 M.2、标准 ATX/mATX 是优势；500W PSU 和 16GB RAM 是首要短板。

对今日挑战者 I10-2574：CPU、Windows Pro、32GB 和远程体验都是明显升级方向；GPU 则没有结构性跨越，因此它更像“CPU/远程 workstation 升级”，而不是“GPU workstation 升级”。
