### 相对固定 Reference 的实际升级 / 退步

固定 Reference 来自 `data/reference_systems.csv`：**HP Z2 Tower G9 Workstation，Intel Core i7-12700K、32GB RAM、Intel UHD Graphics 770**。该 Reference 没有价格，绝不进入 `price_history.csv`、7/30 天均值或折扣统计。

- **CPU：退步。** 5700X 为 8C/16T，Reference 的 i7-12700K 为 12C/20T。没有用未经核验的百分比；在 CPU 密集型仿真、编译、大型装配和多任务场景，Reference 更值得保留。
- **GPU：明显升级。** RTX 5060 8GB 相比 UHD 770 能提供独显 CUDA / OptiX / 视口加速；但 8GB 显存会限制大型场景。若软件主要依赖 CPU，独显并不能抵消 CPU 退步。
- **RAM：容量相同。** 两边都是 32GB；CSL 主板有 4 DIMM 和更高扩容上限，但当前仍是 DDR4。
- **远程主机：有条件升级。** CSL 需要另装 Windows Pro 才能作为原生 RDP 主机；Reference 的操作系统版本未在固定基准表记录。CSL 有 1GbE / WoL，但没有 Wi-Fi，也没有 CPU 集显；显卡可提供 NVIDIA 硬件编码，Reference 则保留 Intel iGPU / Quick Sync 作为备用路径。
- **功耗 / 散热：** 5700X + RTX 5060 的独显整机功耗高于纯 UHD 770 配置；500W PSU 的升级余量有限。机箱噪声和满载温度没有可核验测试，地下室仍要留出进出风空间并定期除尘。
- **五年升级：** CSL 的标准 mATX / 4 DIMM / 128GB 比封闭 OEM 平台更友好，但 AM4、单 M.2、PCIe 3.0 和 500W PSU 是明确短板。

**结论：不要为了 CPU 性能替换 HP Z2 G9。** CSL 只有在你需要一台独立 NVIDIA GPU 节点、而现有 HP 的电源/空间/兼容性不允许加显卡时才有意义。若 HP Z2 G9 的 PSU、显卡长度和 PCIe 供电允许，先核算给现有 HP 加显卡的成本，可能比换一台 CPU 更弱的整机合理。

## 7. 购买前核对清单

1. 若选 CSL：确认 500W PSU 的具体型号、风扇布局和显卡供电线；若计划升级显卡，预留更换标准 ATX PSU 的预算。
2. CSL 若作为远程主机，先解决 Windows 11 Pro 授权；接入有线 1GbE，开启 WoL / AC Power Recovery，并考虑 UPS。
3. 若选 KRAFTPC：下单前要求卖家书面给出 Gigabyte A520M 的完整型号、DIMM 数量、M.2 数量/代数、PCIe 规格，以及 650W PSU 的完整型号。
4. 若考虑 Acer 翻新：先取得桌面机保修期限、保修责任方、划痕照片和 32GB RAM 升级确认；未书面确认保修不要下单。
5. 不要为了独显把 HP Z2 G9 的 CPU 优势丢掉。先核对 HP 的 PSU、PCIe 供电和机箱空间，判断给现有 HP 加显卡是否更经济。
