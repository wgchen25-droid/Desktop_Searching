## 冠军的配置、适配与风险

### CPU / GPU / RAM / SSD

- CPU Ryzen 5 5600：6核12线程、65W；这是预算内的中端 AM4 CPU，不是工作站级 CPU。
- GPU RTX 5060 8GB：有 CUDA，适合 CUDA/OptiX、GPU渲染、AI推理和部分工程视口；8GB VRAM 对大装配、复杂贴图和大模型会成为限制。具体显卡厂牌和接口数量没有在配置器中锁定，必须让商家书面确认。
- RAM 32GB Kingston Fury Beast 2×16：双通道；B550板有4 DIMM，仍有两槽可扩。
- SSD WD SN3000 1TB NVMe。商家页面在不同描述段落对 Gen3/Gen4 标注不一致，需确认实际 SKU 和接口速率。

### 主板、PSU、散热、网络

- Gigabyte B550 Gaming X V2 是标准 ATX，官方规格为4 DIMM、双 M.2、PCIe 4.0 x16、GbE LAN；无板载 Wi-Fi。
- 650W be quiet! System Power 11 B Bronze 是标准 ATX PSU，不是专有电源。足以服务当前 RTX 5060；若未来换高功耗旗舰 GPU，可能需要连电源一起升级。
- AirForce GT1 ATX机箱、空气冷却器和3个120mm机箱风扇；没有独立噪音/温度测试，地下室放置应留出进排风空间。
- 1GbE有线网络适合长期远程主机；默认没有 Wi-Fi。

### 工程软件和远程多屏

- 适合：CUDA/OptiX、GPU渲染、AI工具、一般 CAD/3D视口和多任务工作站。
- 不适合：依赖大量 CPU 核心的仿真、复杂重建、大型装配和超过8GB显存的工作负载。
- Windows 11 Pro 可作为原生 RDP Host；Microsoft 文档明确支持使用全部客户端显示器。地下室主机建议有线1GbE、固定 DHCP 地址、禁用睡眠，并通过 UPS 保护。
- NVIDIA 参考规格的 RTX 5060 可支持最多4台显示器，但整机配置器未锁定具体显卡厂牌/接口，购买前仍需确认实际输出端口。

### 五年升级

- 优点：ATX主板、4 DIMM、双 M.2、PCIe4 x16、标准ATX PSU和机箱，避免了不少整机专有件风险。
- 缺点：AM4已到平台末期，未来主要是 Ryzen 5000 系列 CPU、RAM、SSD和显卡升级；没有 DDR5/AM5路径。
- 650W Bronze不是未来旗舰显卡的长期保证。五年内若换高端GPU，可能要换 PSU。

### 售后和退货

- 实际销售方 IT-Systemtreff GmbH，德国直接销售，3年系统保证。
- 商品页宣传30天退货；但其撤回权条款排除按客户个人选择制作的商品。因为此处选择了 RAM 和主板配置，**不要仅凭页面横幅假定定制机一定可无条件退货**。下单前要求商家邮件确认本配置是否适用30天退货，以及返程运费由谁承担。
