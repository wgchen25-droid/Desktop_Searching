## 相对固定 Reference 的实际升级 / 退步

固定 Reference 仍是 **HP Z2 Tower G9 Workstation：Intel Core i7-12700K / 32GB RAM / Intel UHD Graphics 770**，并且**没有价格**。它继续只用于硬件比较，绝不进入 `price_history.csv`，也不参与 7 天/30 天均值、市场折扣或历史最好价。

### HP OMEN 相对 HP Z2 Tower G9

**CPU：不是无条件升级。** Intel 官方规格显示 i7-12700K 为 12 核（8P+4E）/20 线程，处理器基础功耗 125W、最大睿频功耗 190W；AMD 官方规格显示 Ryzen 7 8700F 为 8 核/16 线程、65W 默认 TDP。没有用未经核验的百分比声称谁在你的具体工程 workload 快多少。对于高度并行的 CPU-only solver、编译和 CPU 渲染，Z2 的 12700K 仍可能很有竞争力；8700F 的价值更偏 AM5/DDR5 平台和更低 CPU 标称功耗，而不是“CPU 必然更快”。

**GPU：这是最实质的升级。** 从 UHD 770 到 RTX 5070 12GB，CUDA/OptiX、GPU 渲染、AI、GPU 求解器和大型 3D 视口会获得能力级别的提升。没有给出“快几倍”，因为不同工程软件、模型规模和 GPU 后端差异很大。

**RAM：容量持平。** 两边都是 32GB；OMEN 的 DDR5 与 4 DIMM 为后续扩容加分。大型有限元、CFD、大程序集或多 VM 工作流仍可能值得升 64GB。

**远程主机：OMEN 的 GPU/编码能力更强，但 Z2 的 workstation 属性仍有价值。** OMEN 适合 GPU 加速桌面、远程 3D 和多屏编码；长期无人值守应优先有线网络、关闭不必要睡眠，并确认 BIOS 的断电恢复/自动开机选项。Windows 11 Home 若使用微软原生 RDP 作为被控 Host，需要升级到支持该功能的版本或改用其他远程方案。

**功耗/散热：不能只看 CPU TDP。** 8700F 的 65W 默认 TDP低于 12700K 的 125W基础/190W最大睿频功耗，但 OMEN 增加了 RTX 5070，GPU 满载时整机功耗显然会远高于只用 UHD 770 的 Z2。地下室长期运行真正要关注的是机箱风道、灰尘、风扇/泵可靠性和持续 GPU 负载。

**五年升级：OMEN 的 AM5/B650/DDR5 路线更现代，但标准件透明度不如真正 ATX 自组式整机。** 如果 Z2 当前瓶颈只是 CPU 多核而不是 GPU，今天不值得仅为 OMEN 换机；如果瓶颈是 CUDA、GPU 渲染、AI 或大型 3D，OMEN 才是明确的实际升级。
