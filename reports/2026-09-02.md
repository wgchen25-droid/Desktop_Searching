## 相对固定硬件 Reference 的实际升级 / 退步

该 Reference 没有价格，因此继续严格排除在 `price_history.csv`、7/30 天价格统计、市场折扣和历史最低价之外。

### 今日主推 Speed 4574 vs HP Z2

**CPU：不是全面升级。** 2026-09-02 的 PassMark 平均数据为：Core Ultra 5 225F CPU Mark 约 **31,001**、Single Thread **4,401**；i7-12700K CPU Mark 约 **34,254**、Single Thread **4,003**。按同一数据库计算，225F 综合 CPU Mark 约低 **9.5%**，单线程约高 **9.9%**。这只是合成 benchmark，不等于具体 CAD/CAE 软件的实际比例。

因此，纯 CPU 多核仿真、CPU 渲染、长时间并行任务并不构成明确升级；交互式 CAD、部分单线程敏感操作可能略有优势。

**GPU：这是 Speed 4574 真正的升级。** Reference 只有 UHD 770，而 Speed 4574 是 RTX 5070 12GB。对于 CUDA、GPU 渲染、AI、部分仿真、视频处理和重 3D 视口，这是能力层级的变化。没有使用“快多少倍”的虚假数字，因为没有找到足够统一且适用于工程 workload 的可核验比较。

**RAM：明确退步。** HP 是 32GB，Speed 只有 16GB。因此如果购买，32GB RAM 应视为实际购买成本的一部分；长期工程主机建议 64GB。

**远程主机：GPU 侧更强，但平台扩展更弱。** RTX 5070 适合硬件编码和多显示输出，有线 LAN 也适合固定地下室主机；但 H810M 的 DIMM、M.2 和 PCIe 扩展明显不如工作站平台。

**功耗 / 散热：** 225F CPU 侧比 12700K 更容易控制热量，但 Speed 额外加入高性能独显，因此 GPU 满载时整机功耗和热量必然高于仅使用 UHD 770 的 Reference。没有完整墙上功耗实测，因此不提供伪精确整机百分比。

**五年升级：** Speed 使用常规 DIY 风格零件，显卡、电源、内存更容易自行替换；但 H810M 本身是短板。HP Z2 的 W680 工作站平台在 DIMM / M.2 / 管理方面更成熟，但 OEM 机的电源、机箱、布线自由度通常较低。

### 新候选 Sprint 5928 vs HP Z2

这台更接近“CPU + 平台一起升级”。PassMark 2026-09-02 的 Ryzen 9 9900X 平均 CPU Mark 约 **54,327**、Single Thread **4,673**。相对 i7-12700K 的 34,254 / 4,003，同一数据库下约为 **CPU Mark +58.6%**、单线程 **+16.7%**。仍需强调：这是合成 benchmark，不代表每个工程软件都会同比例加速。

在 CPU 多核仿真、编译、CPU 渲染和高并发任务上，9900X 比 Reference 更有理由称为实际升级。它的 120W 默认 TDP 与 AMD 官方规格一致。

GPU 方面，RX 9060 有 **8GB GDDR6、132W 典型板卡功耗、AV1 编解码、DisplayPort 2.1a / HDMI 2.1b**。它相对 UHD 770 是显著的独显能力补齐，但它不是 NVIDIA GPU；如果软件明确依赖 CUDA，则它并不能完成 Speed 4574 那条升级路径。

RAM 仍是退步：16GB < 32GB，因此 Sprint 5928 同样必须先补到 32GB，长期更建议 64GB。好处是 B850 平台的 M.2、PCIe、Wi‑Fi 和 AM5 CPU 升级路线明显更适合五年使用。

**结论：**

- 如果现有 HP Z2 的痛点是 **CUDA / GPU 渲染 / AI / 重 3D**：Speed 4574 仍是今天更有意义的替换候选。
- 如果痛点是 **CPU 多核、编译、通用工程计算，同时想要标准 AM5/B850 长期升级**：Sprint 5928 是今天新出现的更合理路线。
- 如果 HP Z2 当前只做 Office、2D CAD、轻量建模和普通远程桌面，则两台都不是“必须换”。
