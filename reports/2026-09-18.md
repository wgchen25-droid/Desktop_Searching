## CSL Sprint 5753：工程软件 / 远程 / 升级

### CPU

Ryzen 7 8700F 是 8 核 16 线程。对通用 CAD、MATLAB、中等编译与工程桌面足够，但它不是今天购买的主要价值点；真正价值来自 16GB NVIDIA 独显与 AM5 平台。

### GPU

RTX 5060 Ti 16GB 对 CUDA / OptiX、NVIDIA GPU solver、本地 AI、GPU 渲染、复杂 3D 视口和较大显存任务都有结构性优势。16GB 显存也比同预算常见 8GB 型号更适合长期工程用途。

### RAM / SSD

开箱 16GB 是最大短板。相对当前 32GB Reference 明确退步，建议购机时直接把 32GB（最好 2×16GB）视为实际总成本的一部分。1TB PCIe NVMe 是合理起点；B840M 平台的标准化扩展比 OEM 整机更适合后续加盘。

### 网络 / 远程

2.5GbE + Wi-Fi 6E 对地下室/角落主机很合适，但主链路仍建议使用有线 Ethernet，Wi-Fi 留作备用管理。机器无 OS；若依赖微软原生 Remote Desktop 作为被控 Host，应安装 Windows 11 Pro。Windows 11 Home 不能作为微软原生 RDP Host。

### PSU / 散热

500W Bronze 足够当前 8700F + RTX5060Ti 组合，但它是未来上高功耗显卡时的第一硬件瓶颈。长期固定运行建议保证机箱进出风、定期清灰、避免贴墙堵住进风口，并在 BIOS/系统里配置稳定的风扇与电源策略。

### 五年升级

AM5/B840/DDR5 是今天它胜过多台更便宜 AM4 成品的根本原因。RAM、M.2、GPU、PSU 都是标准桌面件；未来 CPU 平台仍有明显余地。相比品牌 OEM 小机箱，专有零件风险较低。长期路线建议：先补 RAM → 再扩 SSD → 未来若换更高功耗 GPU，同时换更高规格 ATX 电源。

## 相对固定 Reference：HP Z2 Tower G9 / i7-12700K / 32GB / UHD 770

Reference 继续只作为固定硬件参照；`price_eur` 为空，不进入任何市场价格历史、7 日/30 日均值、折扣或历史最低价统计。

**CPU：CSL 不是升级。** 同一 PassMark 口径下，i7-12700K 约 34.3k CPU Mark，Ryzen 7 8700F 约 30.9k；方向上 8700F 的合成多线程约低 **9.8%**。单线程差距约 **3%** 左右。合成 benchmark 不能直接等同于 ANSYS、Abaqus、MATLAB、SolidWorks 等具体任务，但足以说明：CPU-only solver、CPU 渲染、编译等不应因为买 CSL 而期待明显加速。

**GPU：CSL 是结构性升级。** UHD 770 → RTX5060Ti 16GB 会获得 CUDA/OptiX、独立显存和 NVIDIA GPU 计算/渲染生态；如果当前 Z2 的真实瓶颈是 GPU、CUDA、AI 或 3D 视口，这是换机的核心理由。

**RAM：开箱退步。** Z2 是 32GB，CSL 只有 16GB，所以必须把 RAM 扩容算入购买成本。

**远程：网络更现代，但软件要补齐。** CSL 的 2.5GbE/Wi-Fi 6E 很适合固定远程主机；无 OS 意味着需要自己装 Windows/Linux。需要原生 RDP Host 时优先 Windows 11 Pro。

**功耗/散热：CPU 本身更省，但整机 GPU 负载更热。** 8700F 的 CPU 功耗等级较低，但 RTX5060Ti 长时间满载会让整机热量高于只使用 UHD 770 的 Z2。地下室长期运行要更重视风道和灰尘管理。

**五年空间：CSL 更模块化。** AM5/DDR5 与标准 mATX/ATX 部件的可换性优于多数 OEM；但 Z2 的企业工作站级稳定性、管理与售后体系仍有优势。若当前工作几乎都是 CPU-only，继续使用 Z2 比换 CSL 更合理。
