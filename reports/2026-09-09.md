### CPU：Captiva 明确退步

PassMark 的同一直接对比页当前给出：

### GPU：Captiva 是结构性升级

RTX 5070 官方规格为 **6144 CUDA cores、12GB GDDR7**。相对 UHD 770，它真正胜出的场景包括：

- CUDA / OptiX；
- GPU 渲染；
- 本地 AI / 推理；
- 支持 NVIDIA GPU 的求解器；
- 大型 3D 视口与 GPU 加速可视化。

没有针对你的具体工程软件建立统一公开 benchmark，所以不硬写“快几倍”。如果当前 Z2 的瓶颈主要是 GPU/CUDA，Captiva 才有明确换机意义；如果工作主要是 CPU-only、2D CAD、Office、普通远程桌面，则更换整台机器未必划算。

### RAM

两者都是 **32GB**，所以 Captiva 不是容量升级。对复杂工程模型、多 VM 或大数据集，二者都可能需要升到 64GB。

### 远程主机能力

Captiva 有 1GbE + Wi-Fi 6，作为地下室主机网络路径更灵活；但 Windows 11 Home 不能直接作为微软原生 Remote Desktop Host，若采用原生 RDP，需要升级 Pro。HP Z2 若当前已装 Pro，则这点反而是现有 Reference 更省事。

### 功耗 / 散热

Ryzen 7 5700X 的 CPU 额定功耗明显低于 12700K 的高功耗上限，但 Captiva 同时加入 RTX 5070。**因此不能把“CPU 更省电”误写成“整机一定更省电”**：GPU 满载时 Captiva 整机功耗会显著高于只用 UHD 770 的 Z2。长期放地下室应重点保证进风、防尘和排热，而不是只看 CPU TDP。

### 五年升级空间

Captiva 的常规桌面 PSU / B550M 生态在“换 GPU、加 RAM、换 SSD”方面比较友好，也比很多大厂 OEM 的专有电源/线序风险低；但 AM4/DDR4 CPU 平台基本到末期。HP Z2 的 workstation 底座在扩展槽和专业维护上有优势，但也存在 OEM/专有件生态。结论是：**Captiva 的五年优势主要在独显和常规 PC 零件，而不是 CPU 平台寿命。**
