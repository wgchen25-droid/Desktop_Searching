### 今日总冠军相对 Reference 的实际升级 / 退步

**CPU：不是升级。** PassMark 当前可核验数据里 Ryzen 7 8700F CPU Mark 约 **30,882**、单线程约 **3,873**；i7-12700K 的同类 PassMark 数据约 **34,256**、单线程约 **4,003**。按同一指标计算，8700F 的多线程 CPU Mark 约低 **9.8%**，单线程约低 **3.2%**。这些只是合成 benchmark，不能直接等同于某个 CAD/CAE 软件的百分比，但足以说明 CPU-only solver、CPU 渲染、编译等任务不应把 OMEN 当成 CPU 升级。

**GPU：结构性大升级。** NVIDIA 官方规格显示 RTX 5070 有 **6144 CUDA cores、12GB GDDR7、250W TGP，并支持最多 4 个独立显示器**。相对 UHD 770，真正值得替换 Reference 的场景是 CUDA / OptiX、GPU 渲染、AI、本地推理、重 3D 视口和显存敏感工作。没有同一工程 workload 的可靠 benchmark，因此不写“快几倍”的猜测。

**RAM：容量持平。** 两边都是 32GB。OMEN 是 2×16GB 且有 4 DIMM；长期工程使用可以考虑 64GB。

**远程主机：GPU/显示能力升级，但 OS 有坑。** RTX 5070 支持最多 4 个独立显示器，OMEN 也有有线和无线网络；但微软官方明确要求被远程连接的 Windows PC 运行 Pro 版才能作为原生 Remote Desktop Host。OMEN 自带 Home，因此需要升级 Pro 或使用其他远程方案。

**功耗/散热：CPU 更省，GPU-heavy 总功耗更高。** 8700F 约 65W TDP；12700K 可到约 190W 最大 boost 功耗级别。但 RTX 5070 本身参考 TGP 为 250W，所以 GPU-heavy 工作时 OMEN 的整机热量会显著高于只用 UHD 770 的 Reference。地下室长期运行仍要保证进出风和定期除尘。

**五年升级：各有优势。** OMEN 的 B650 / AM5 对未来 CPU 路线更友好；固定 Z2 G9 的 W680 workstation 机型家族则提供 4 DIMM、更多 PCIe 槽和最多 3 个 M.2 2280 存储位，物理扩展能力并不差。OMEN 的 OEM 规范透明度不如标准 ATX 装机，因此这里不能简单说“全面升级”。

### 哪些情况下不值得替换 Reference？

如果你现在主要跑的是 CPU-only solver、编译、2D CAD、Office、轻量远程桌面，而且 UHD 770 没成为瓶颈，**今天依然不值得为了换机而换机**。真正合理的购买触发条件是：现有 Z2 已明显被 GPU/CUDA/显存/3D 视口/AI workload 限制。
