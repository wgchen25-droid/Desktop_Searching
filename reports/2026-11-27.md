### 工程软件适配

- RTX 5060 的 CUDA、GPU 渲染和较复杂的 3D 视口，是这台机器的主要价值。
- 8GB VRAM 是明显限制：大型装配、超大纹理、复杂渲染场景和本地 AI 工作负载可能很快触及显存上限。
- GeForce 不自动等于专业工作站 ISV 认证显卡；如果目标 CAD/CAE 软件明确要求认证驱动，应优先核对软件厂商认证清单，而不是只看游戏 GPU 性能。
- Ryzen 7 5700X 足以处理常见多任务，但不应把它视为对 i7-12700K 的 CPU 升级。

### 远程主机与多屏

- Windows 11 Pro 可作为原生 Remote Desktop 主机；微软要求被远程连接的 PC 使用 Windows Pro。
- RTX 5060 的 3×DP + HDMI 适合最多四屏本地输出；RDP 客户端也支持在远程会话中使用多个显示器。5700X 没有集成显卡，独显故障时没有主板视频输出作为本地恢复后备。
- 地下室长期放置建议使用有线 1GbE，不要依赖随附 USB Wi-Fi。
- ASUS 官方主板规格列出 WOL by PME；但 Kiebel 的 BIOS 默认值和随附 USB 无线适配器的唤醒行为没有独立确认。地下室无人值守建议走板载 1GbE，并在放置前测试 BIOS/Windows 的 WOL。
- 建议关闭自动睡眠、配置断电恢复策略，并给路由器/主机保留 DHCP 地址。

| 升级 | HP OEM 工作站，具体 PSU / 插槽需查实际机器部件号 | 标准 mATX / ATX 组件，但 AM4/A520 已成熟，1 个 M.2、PCIe 3.0 |

**实际结论：**

1. CPU 是退步，不是升级。i7-12700K 有 12 核 20 线程；5700X 是 8 核 16 线程。没有在相同测试平台下的可靠 benchmark，就不报百分比。
2. GPU 是明显升级：RTX 5060 对 CUDA、GPU 渲染和复杂视口比 UHD 770 更有意义，但 8GB 显存会限制大型工程场景。
3. RAM 容量不变。Kiebel 主板可扩至 128GB；Reference 记录没有提供 DIMM 数量和最大容量，不能直接断言 Kiebel 的内存扩展一定更好。
4. CPU 密集型 FEA / CFD、编译、批处理可能继续由 HP Reference 更适合；GPU 加速渲染、CUDA 和较复杂视口则 Kiebel 更有优势。
5. Kiebel 的 Windows 11 Pro 是远程主机优势；RTX 5060 的四屏输出也方便本地维护。但 HP 的 Windows 版本没有记录，不能说 HP 无法做 RDP。
6. Kiebel 的 CPU 更低功耗，但独显增加整机功耗和热量；没有整机实测功耗、温度和噪音，不能单凭 CPU TDP 判断整机更省电。
7. 若 HP Z2 目前稳定工作，**不建议为了这台 Kiebel 把 HP 换掉**。更合理的路线是先核对现有 HP 的 PSU 型号、PCIe 插槽和机箱空间，再判断能否只升级 GPU；这可能比购买整机更经济。
