## 为什么 CSL 仍然胜过 KIEBEL 与 GameMachines

CSL 的优势不是开箱配置最豪华，而是把预算放在最难补、长期价值最高的部分：**RTX 5060 Ti 16GB + AM5/B840/DDR5**。KIEBEL 多给 16GB 系统内存、Windows 和更大的 650W PSU，但 GPU 显存只有 8GB、CPU 平台停在 AM4/A520；GameMachines 更便宜且有 Win11 Pro，但同样只有 8GB VRAM、16GB 系统内存，并且主板/PSU 不透明。对 Office、2D CAD、普通远程桌面，后两者的开箱便利很真实；对 CUDA/OptiX、本地 AI、大纹理、GPU solver、复杂 3D 视口，以及未来逐步换 CPU/RAM/GPU，CSL 更符合五年目标。

NEXOC Captiva R93-435 则是“多花 €146.99 换当前更强 GPU 和完整配置”的路线：RTX5070 12GB、32GB、Windows、Wi‑Fi、明确型号 MSI 850W 都比 CSL 更省事，但 AM4/B550/DDR4 的 CPU 平台寿命明显较短。

## 主板、网络、散热、稳定性与升级

CSL 的 ASUS PRIME B840M-A WIFI 是标准 mATX / AM5 主板，已核验具备 4 个 DDR5 DIMM、3 个 M.2、CPU 直连 PCIe x16、2.5GbE 与 Wi‑Fi 6E。机器采用标准件布局，后续换 RAM、SSD、PSU、GPU 都比多数 OEM 小塔更容易。500W Bronze 是当前最明显的长期约束：RTX5060Ti 可以使用，但将来升级更高功耗 GPU 时应同步换到更高质量、更新 ATX 规范的 650–850W PSU。

出厂 16GB DDR5 是工程用途的明确短板。建议购机时直接把总成本按“至少 32GB”计算；大型装配、多 VM、大网格/结果文件或本地 AI 工作可考虑 64GB。1TB SSD 足够起步，但工程缓存和结果文件通常增长很快，3 个 M.2 为后续扩容提供了比较舒服的空间。

地下室/角落长期运行建议固定走有线 2.5GbE，Wi‑Fi 6E 作为备用管理链路。长期 GPU 满载时整机热量会明显高于仅使用核显的旧工作站，因此要留出进排风空间、控制灰尘与湿度，并定期清灰。

## 相对固定 Reference：HP Z2 Tower G9 / i7-12700K / 32GB / UHD 770

`data/reference_systems.csv` 中的 HP Z2 Tower G9 仍然没有价格，只作为固定硬件 Reference；**没有写入 `price_history.csv`，也没有参与 7 日/30 日均值、市场折扣或历史最好价统计。**

CSL 5753 **不是 CPU 升级型换机**。Reference 的 i7-12700K 是 12 核 / 20 线程，而 8700F 是 8 核 / 16 线程；公开合成基准通常仍把 12700K 放在 8700F 之上。因此 CPU-only solver、编译、CPU 渲染，以及部分 CPU 敏感 CAD 工作不能假定换 CSL 会变快。这里不把合成 benchmark 百分比直接等同于 ANSYS、Abaqus、SolidWorks 或 MATLAB 的真实提升。

真正的结构性升级是 **UHD 770 → RTX 5060 Ti 16GB**：CUDA、OptiX、NVIDIA GPU solver、本地 AI、GPU rendering、复杂 3D 视口和显存敏感场景会得到能力级提升。反过来，系统 RAM 从 Reference 的 32GB 降到 CSL 开箱 16GB 是明确退步，因此 32/64GB RAM 升级应直接算入购机计划。

远程主机能力方面，CSL 有更现代的 2.5GbE/Wi‑Fi 6E 与独显多屏输出，但没有预装 Windows；Reference 若已经稳定运行 CPU/Office/2D 任务且 GPU 不是瓶颈，今天没有必要为了“新机器”本身替换它。功耗上 8700F CPU 属于较低功耗等级，但加入独显后，GPU 长负载时 CSL 整机散热压力会高于仅使用 UHD770 的 Reference。
