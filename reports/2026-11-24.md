### 与固定 Reference 的实际升级 / 退步

固定 Reference 来自 data/reference_systems.csv：**HP Z2 Tower G9 Workstation — Intel Core i7-12700K、32GB RAM、Intel UHD Graphics 770**。该 Reference 没有价格，完全不进入 price_history.csv、7/30 日均价、市场折扣或历史最低价。

- **CPU：退步。** Ryzen 7 5700X 是 8C/16T、65W；i7-12700K 是 12C/20T（8P+4E）。不引用未经核验的性能百分比：从核心配置和平台定位看，Reference 更适合 CPU 密集型仿真、编译和大型装配。
- **GPU：明显升级。** RTX 5060 8GB 相比 UHD 770，能为 CUDA / OptiX、GPU 渲染、3D 视口和部分 AI 工具提供独显加速；但 8GB 显存限制大型工程场景。
- **RAM：持平。** 两者都是 32GB；CSL 主板最多 64GB，Reference 的主板扩展规格在当前 Reference CSV 中没有记录，不能假设。
- **工程软件：** GPU 加速场景 CSL 胜；CPU 主导的有限元、求解器、编译和大装配未必胜，可能反而不如现有 HP Z2。
- **远程主机：** CSL 的 RTX 5060 可接最多四个显示器，1GbE 有线可用；但没有 OS，RDP 主机需 Pro，WOL 也未核实。Reference 的 UHD 770 仍有 Quick Sync 价值，实际显示输出数量取决于 HP 主机端口。
- **功耗 / 散热：** 5700X 的 CPU 标称功耗低于 12700K，但 CSL 增加了独显热量；500W PSU 余量有限，不能只凭 65W CPU 判断整机功耗。
- **五年空间：** CSL 是标准 mATX / ATX PSU，非明显专有零件；但 AM4、64GB 上限和 500W PSU 是短板。

**结论：不要为了这台机器替换仍然健康的 HP Z2 G9。** 它更适合作为补充的 NVIDIA GPU 节点；如果主要瓶颈是 CPU 仿真或大装配，现有 Reference 仍有实际价值。
