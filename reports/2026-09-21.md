## 为什么 Acer 今天继续赢

Acer 的优势依然是把 **RTX 5070 12GB + Windows 11 Home + 850W Gold** 压进 €1,159 的实际现金支出。精确 SKU 公开数据还确认：16GB DDR4 为 2×8GB、总共只有 2 个 DIMM 且已占满、最大 32GB；1TB M.2 SSD、1GbE、Wi‑Fi 6E、1×HDMI + 3×DisplayPort。作为廉价 CUDA / GPU rendering / 本地 AI / NVIDIA 加速工程节点或远程 3D 主机，它的 GPU/欧元非常强。

但它不是理想的长期 workstation 底座：OEM / H610 级主板、LGA1700、DDR4、只有 2 DIMM / 最大 32GB、PCIe / M.2 扩展空间有限，专有部件风险也高于标准 ATX/mATX 成品。它适合“便宜买强 GPU，四五年主要加 SSD / 把 RAM 换成 32GB”，不适合“未来持续换 CPU、扩 64/128GB RAM、堆多张 PCIe 卡”。

## Acer vs CSL：多 €140 买到什么

**Acer €1,159 → CSL €1,299，多 €140。** Acer 保留 RTX 5070 12GB、Windows 11 Home 和 850W PSU；CSL 则是 RTX 5060 Ti 16GB、无 OS、500W PSU、16GB RAM，所以“今天就跑 GPU 任务”的性价比 Acer 更强。

CSL 的 €140 主要购买的是**全新状态 + AM5/B840/DDR5 + 标准 mATX + 4 DIMM + 3×M.2 + 2.5GbE + Wi‑Fi 6E + 24 个月厂家保修**。如果机器要在地下室长期放置，未来五年会逐步加 RAM / SSD、换 CPU，CSL 的维护和升级路线明显更健康；其 500W PSU 则应视作未来高功耗 GPU 升级时的第一批更换部件。

## 相对固定 Reference：HP Z2 Tower G9 (i7-12700K / 32GB / UHD 770)

`data/reference_systems.csv` 中的 HP Z2 继续只作为**固定硬件 Reference**：i7-12700K / 32GB / UHD 770，价格字段为空。本日报没有把它写进 `price_history.csv`，也没有让它参与市场折扣、7日/30日均价或历史最低价统计。

对今日 Acer 冠军，结论仍然是“**GPU 大升级，CPU 与 RAM 退步**”。PassMark 2026-09-21 同一数据库口径：i7-12700K 为 **34,247 CPU Mark / 4,003 单线程**，i5-14400F 为 **25,439 / 3,701**；即 Acer 的 CPU 合成指标方向约 **-25.7% 多线程、-7.5% 单线程**。这只是合成 benchmark，不能直接等同于 ANSYS / Abaqus / MATLAB / SolidWorks 的真实差距，但足以说明 CPU-only solver、CPU rendering、编译等不应为了这台 Acer 替换 Z2。

GPU 则相反：RTX 5070 官方规格为 **6,144 CUDA cores、12GB GDDR7、250W TGP**，并支持最多 4 个显示器；从 UHD 770 到 RTX 5070，CUDA / OptiX、GPU rendering、NVIDIA GPU solver、本地 AI、复杂 3D 视口属于能力层面的跃升。由于没有针对用户具体工程软件的一致公开 benchmark，这里不编造“快几倍”。RAM 从 Reference 的 32GB 降到 Acer 的 16GB，且 Acer 最大只能到 32GB，所以在大内存场景最多追平 Reference，不能进一步扩到 64/128GB。

远程主机方面，Acer 的 1GbE + Wi‑Fi 6E 足够，但固定地下室主链路仍建议有线 Ethernet；Wi‑Fi 作为备用管理路径。其 Windows 11 Home **不能作为微软原生 Remote Desktop Host**，若依赖原生 RDP 被控端，应升级到 Pro 或采用其他远程方案。功耗/散热上，i5-14400F CPU 本身较温和，但 RTX 5070 官方 TGP 250W；长期高 GPU 负载时整机热量会明显高于只用 UHD 770 的 Z2，应确保进排风、灰尘过滤和定期清洁。
